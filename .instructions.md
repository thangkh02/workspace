# OpenClaw Instructions - Facebook Group Operations

## Primary Function

**Extract Facebook posts from a given group/page link** and return structured data.

## ⚡ CRITICAL: Auto-Execute Rule

> **When a user provides a Facebook group URL and asks to collect posts, the agent MUST immediately execute the pipeline. DO NOT explain, ask for confirmation, or guide the user manually. Just run it.**

Examples of requests that trigger immediate execution:
- "Lấy 5 bài viết từ group https://www.facebook.com/groups/..."
- "Get 10 posts from https://www.facebook.com/groups/..."
- "Extract posts from https://www.facebook.com/groups/..."
- "Thu thập bài viết từ group [URL]"

**Response pattern (CORRECT):**
```
Đang chạy pipeline thu thập bài viết...
[executes scripts/collect_posts_from_group.ps1 immediately]
```

**Response pattern (WRONG - do NOT do this):**
```
❌ "Tôi sẽ sử dụng web_fetch để..."
❌ "Tôi không thể thực hiện yêu cầu..."
❌ "Bạn cần chạy browser tool / fb_group_ops..."
❌ "Hướng dẫn bạn sử dụng..."
```

## How to Use

Simply provide a Facebook link in any of these formats:
- `https://www.facebook.com/groups/123456789`
- `https://www.facebook.com/pages/PageName`
- `https://www.facebook.com/profile.php?id=USER_ID`

**Example request:**
```
Extract posts from: https://www.facebook.com/groups/ttud.2023
Target: 10 posts
```

## Workflow

1. **Receive Input**
   - Parse Facebook URL
   - Extract group ID / page URL
   - Get target post count (default: 10)

2. **Auto-Execute Pipeline** ← DO THIS IMMEDIATELY
   - Run PowerShell: `collect_posts_from_group.ps1`
   - Browser navigates to group automatically via `openclaw browser navigate`
   - Collect & expand all visible posts via `openclaw browser evaluate --fn`
   - Extract metadata: author, time, text, comments count

3. **Process & Return**
   - Python: merge & filter results
   - Generate JSON report with structured data
   - Display human-readable summary

4. **DRY-RUN MODE** ⚠️
   - ✅ Collecting posts (READ ONLY)
   - ✅ Analyzing content
   - ❌ NO posting, commenting, or interactions
   - All actions logged to `data/ledger.json`

## Configure Groups

Edit `data/groups.json` to add rules:
```json
{
  "name": "Group Name",
  "url": "https://www.facebook.com/groups/...",
  "managed": false,
  "auto_submit": false,
  "topic_keywords": ["keyword1", "keyword2"],
  "rules": [
    {
      "type": "filter",
      "keywords": ["python", "nodejs"],
      "action": "include"
    },
    {
      "type": "exclude_author",
      "authors": ["spam_user"],
      "action": "block"
    }
  ]
}
```

## Safe Defaults

- **DRY-RUN is ON** - No actions executed until explicit approval
- **Confidence threshold**: 0.6 minimum for any post
- **Logging**: All operations logged to `data/ledger.json`
- **Data storage**: Posts saved to `data/posts_collection.json`

## Browser Tool API (OpenClaw CLI)

The correct commands to control the browser:

```bash
# Navigate to a URL
openclaw browser navigate <url> --browser-profile <profile>

# Evaluate JavaScript on current page
openclaw browser evaluate --fn "<jsCode>" --browser-profile <profile>

# Evaluate JavaScript from a file (PowerShell syntax)
$jsCode = Get-Content -Path "./scripts/script.js" -Raw
openclaw browser evaluate --fn $jsCode --browser-profile <profile>

# Take a snapshot (DOM state)
openclaw browser snapshot --browser-profile <profile>

# Take a screenshot
openclaw browser screenshot --browser-profile <profile>

# List open tabs
openclaw browser tabs --browser-profile <profile>

# Start / stop browser
openclaw browser start --browser-profile <profile>
openclaw browser stop --browser-profile <profile>
```

> ⚠️ Old API flags `-i <profile>` and `-u <url>` are **deprecated**. Always use `--browser-profile` and separate `navigate` command.
