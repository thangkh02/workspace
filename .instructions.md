# OpenClaw Instructions - Facebook Group Operations

## ⚡ Auto-Execute Rules (QUAN TRỌNG NHẤT)

**Khi user nhắn tin có chứa link Facebook group + (tuỳ chọn) số lượng bài:**
→ **NGAY LẬP TỨC dùng browser tool để thu thập posts. KHÔNG hỏi thêm. KHÔNG giải thích lý thuyết.**

**KHÔNG bao giờ trả lời kiểu này:**
- ❌ "Tôi cần skill fb_group_ops để thực hiện..."
- ❌ "Tôi không có quyền truy cập vào nhóm Facebook của bạn..."
- ❌ "Tôi có thể hướng dẫn bạn cách thực hiện..."
- ❌ "Hãy cho tôi biết bạn muốn tôi giúp không?"
- ❌ Liệt kê danh sách thông tin cần cung cấp khi đã có đủ rồi

**Luồng quyết định:**
```
User nhắn → có link group (facebook.com/groups/)?
  YES → execute browser workflow ngay (dùng targetCount nếu có, mặc định 10)
  NO  → hỏi: "Link Facebook group của bạn là gì?"
```

**Số lượng bài:** Nếu user không nói → mặc định 10. KHÔNG hỏi.

## How to Use

Simply provide a Facebook link in any of these formats:
- `https://www.facebook.com/groups/123456789`
- `https://www.facebook.com/pages/PageName`
- `https://www.facebook.com/profile.php?id=USER_ID`

**Example request:**
```
Extract posts from: https://www.facebook.com/groups/ttud.2023
Target: 10 posts
```

## Workflow

1. **Nhận yêu cầu (Parse Input)**
   - Parse Facebook URL từ message user
   - Lấy target_count (mặc định: 10 nếu không có)

2. **Tự động dùng browser tool (Auto-Execute)**
   - `browser.navigate(groupUrl)` — điều hướng đến group
   - Đợi page load, click "Xem thêm" để expand posts
   - Extract: author, time_label, post_text, comment_count, like_count
   - Scroll nếu cần để đủ targetCount bài

3. **Trả kết quả ngay (Return Results)**
   - Hiển thị danh sách bài với: tác giả, thời gian, nội dung, số bình luận
   - Lưu JSON vào `data/posts_collection.json`

4. **DRY-RUN MODE** ⚠️
   - ✅ Collecting posts (READ ONLY)
   - ✅ Analyzing content
   - ❌ NO posting, commenting, or interactions
   - All actions logged to `data/ledger.json`

## Configure Groups

Edit `data/groups.json` to add rules:
```json
{
  "name": "Group Name",
  "url": "https://www.facebook.com/groups/...",
  "managed": false,
  "auto_submit": false,
  "topic_keywords": ["keyword1", "keyword2"],
  "rules": [
    {
      "type": "filter",
      "keywords": ["python", "nodejs"],
      "action": "include"
    },
    {
      "type": "exclude_author",
      "authors": ["spam_user"],
      "action": "block"
    }
  ]
}
```

## Safe Defaults

- **DRY-RUN is ON** - No actions executed until explicit approval
- **Confidence threshold**: 0.6 minimum for any post
- **Logging**: All operations logged to `data/ledger.json`
- **Data storage**: Posts saved to `data/posts_collection.json`

## Advanced Options

### Periodic Collection (Set in HEARTBEAT.md)
```task
- Collect posts every 4 hour from monitoring groups
- Parse mentions & questions
- Generate daily summary report
```

### Custom Filters
```json
{
  "filter": "has_questions",
  "keywords": ["Ai giúp", "Hỏi", "tư vấn", "?"],
  "min_comments": 5
}
```

### Approval Workflow
1. Agent generates `dry_run_report.txt`
2. Review posts & recommendations
3. Approve specific actions
4. Agent logs & executes

## Commands

### Get summary report
```
@facebook-agent: Generate report for group ttud.2023
```

```

```
