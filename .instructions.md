# OpenClaw Instructions - Facebook Group Operations

## Primary Function

**fb_group_ops là tool dùng để tự động thu thập bài viết từ Facebook group bằng browser, phân tích nội dung, và trả về kết quả có cấu trúc — ở chế độ DRY-RUN (chỉ đọc, không tương tác).**

## ⚡ Auto-Execute Rule (QUAN TRỌNG)

**Khi user cung cấp link Facebook group → NGAY LẬP TỨC bắt đầu thu thập bài viết (DRY-RUN, chỉ đọc), KHÔNG hỏi thêm, KHÔNG giải thích lý thuyết.**

### Kích hoạt tự động khi nhận được:
- Bất kỳ URL dạng `facebook.com/groups/...`
- Kèm hoặc không kèm số lượng bài (mặc định: 10)

**⚠️ Phạm vi an toàn: "Auto-execute" chỉ áp dụng cho pipeline thu thập (read-only/DRY-RUN). Mọi hành động tương tác (comment/post/react) vẫn bắt buộc qua approval workflow.**

### NGHIÊM CẤM (khi đã có link):
- ❌ KHÔNG trả lời kiểu "Tôi có thể hướng dẫn bạn..."
- ❌ KHÔNG liệt kê lý thuyết về cách làm
- ❌ KHÔNG hỏi thêm thông tin khi đã có link
- ❌ KHÔNG chờ xác nhận để bắt đầu thu thập (thu thập là an toàn, DRY-RUN)

### BẮT BUỘC:
- ✅ Parse URL và số lượng từ message của user
- ✅ Mở browser ngay → điều hướng đến group Facebook
- ✅ Thu thập bài viết → xử lý → trả về kết quả
- ✅ Chỉ hỏi thêm nếu KHÔNG có link Facebook nào trong message
- ✅ Vẫn giữ approval workflow cho mọi action tương tác (comment/post/react)

## How to Use

Simply provide a Facebook link in any of these formats:
- `https://www.facebook.com/groups/123456789`
- `https://www.facebook.com/pages/PageName`
- `https://www.facebook.com/profile.php?id=USER_ID`

**Example request:**
```
Lấy 5 bài viết từ group https://www.facebook.com/groups/ttud.2023
```
→ Agent lập tức mở browser, thu thập 5 bài, trả về kết quả. Không hỏi gì thêm.

## Workflow

1. **Receive Input** (tự động, không cần xác nhận)
   - Parse Facebook URL từ message
   - Lấy số lượng bài (nếu có, mặc định: 10)

2. **Auto-Execute Pipeline**
   - Run PowerShell: `collect_posts_from_group.ps1`
   - Browser opens group automatically
   - Collect & expand all visible posts
   - Extract metadata: author, time, text, comments count

3. **Process & Return**
   - Python: merge & filter results
   - Generate JSON report with structured data
   - Display human-readable summary

4. **DRY-RUN MODE** ⚠️
   - ✅ Collecting posts (READ ONLY)
   - ✅ Analyzing content
   - ❌ NO posting, commenting, or interactions
   - All actions logged to `data/ledger.json`

## Configure Groups

Edit `data/groups.json` to add rules:
```json
{
  "name": "Group Name",
  "url": "https://www.facebook.com/groups/...",
  "managed": false,
  "auto_submit": false,
  "topic_keywords": ["keyword1", "keyword2"],
  "rules": [
    {
      "type": "filter",
      "keywords": ["python", "nodejs"],
      "action": "include"
    },
    {
      "type": "exclude_author",
      "authors": ["spam_user"],
      "action": "block"
    }
  ]
}
```

## Safe Defaults

- **DRY-RUN is ON** - No actions executed until explicit approval
- **Confidence threshold**: 0.6 minimum for any post
- **Logging**: All operations logged to `data/ledger.json`
- **Data storage**: Posts saved to `data/posts_collection.json`

## Advanced Options

### Periodic Collection (Set in HEARTBEAT.md)
```task
- Collect posts every 4 hour from monitoring groups
- Parse mentions & questions
- Generate daily summary report
```

### Custom Filters
```json
{
  "filter": "has_questions",
  "keywords": ["Ai giúp", "Hỏi", "tư vấn", "?"],
  "min_comments": 5
}
```

### Approval Workflow
1. Agent generates `dry_run_report.txt`
2. Review posts & recommendations
3. Approve specific actions
4. Agent logs & executes
